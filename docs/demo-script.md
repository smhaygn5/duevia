# Duevia demo script

Target length: 2-3 minutes.

## 1. The problem

Global service work still splits scope, delivery, invoicing, and settlement
across disconnected tools. Both parties carry avoidable trust and payment risk.

## 2. Create clear terms

Open the agreement builder. Show that either the client or provider can define
sequential milestones, exact USDC amounts, delivery dates, review windows, and
revision limits.

## 3. Join without custody

Open the private invitation. Explain that acceptance only links the second
wallet; it does not sign a transaction or move funds.

## 4. Fund globally

Open the funding route. Show direct Arc, Circle Bridge, and Unified Balance
discovery. Explain the three explicit client confirmations: deploy the isolated
escrow, approve the exact USDC amount, and fund.

## 5. Submit protected work

Switch to the provider view. Upload a deliverable, point out private R2 storage,
and submit its proof on Arc. Only the proof is public; the file remains
access-controlled.

## 6. Review and settle

Switch to the client view. Download the delivery, request changes, or approve.
Approval releases only the current milestone and produces an Arc-linked
receipt.

## 7. Show the safety exits

Open recovery. Show mutual cancellation, pre-work cancellation, non-delivery
refund, and provider timeout release as contract conditions rather than support
promises.

## Closing

Duevia turns global service agreements into verifiable stages:
**Work in stages. Settle globally.**
